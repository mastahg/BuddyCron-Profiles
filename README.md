BuddyCron Profiles
==================

Questing profiles for [**BuddyCron**](https://buddycron.com), converted from the original
[BuddyWing](https://buddywing.net) collection. Questing may require user interaction from time to time.

Layout
------

Profiles are filed by contributor. Where a contributor split their work, it is by faction and
alignment: `<Contributor>/<Republic | Empire>/<Light | Dark>/`.

| Path                       | Contents                                                        |
|----------------------------|-----------------------------------------------------------------|
| `Orlok/`                   | Orlok Raven's class stories, 1-29, one file per class and side. |
| `Kick/`                    | Kickazz006's 1-50 chains, space missions, grinding and utility profiles. |
| `CryoGenesis/`             | Republic 10-29 chain and level 55 dailies.                      |
| `Silentfu72/`              | Republic Dark 1-37 chain.                                       |
| `Metrienne/`               | 1-10 starter planets.                                           |
| `DotbyDot/`                | Empire 50-55 Makeb.                                             |
| `Joe/`, `Willox profiles/` | Belsavis and Ilum level 50 dailies.                             |

Chained profiles hand off to the next planet with `LoadProfile`, which names a file in the same
directory.

The unmodified BuddyWing originals are on the `originals` branch, for reference.

Contributing
------------

Want to add your own profiles? Get in touch with one of the current contributors.
